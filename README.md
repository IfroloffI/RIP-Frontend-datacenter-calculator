# Разработка интернет-приложений (РИП) 2025

## Тема: Расчет потребляемой датацентром электроэнергии в зависимости от оборудования в нем

Объектом разработки является информационная система для расчета энергопотребления дата‑центра и годового потребления электроэнергии на основе выбранного оборудования и коэффициента энергоэффективности PUE (Power Usage Effectiveness). Цель работы заключается в создании комплекса, включающего основной веб‑сервис, дополнительный асинхронный сервис на Java Spring Boot, веб‑приложение и нативное приложение на Tauri, который позволяет системным администраторам формировать заявки на расчет мощности и энергопотребления ЦОД, а системным инженерам дата‑центра управлять каталогом оборудования и обрабатывать эти заявки.
